# GitLab Time Tracker

Локальное веб-приложение, которое показывает, сколько времени вы залогировали
в GitLab (`/spend`) по дням: дневной график часов, разбивка по проектам и
список записей с ссылками на issue/MR.

## Как это работает

- Данные тянутся напрямую из **GitLab GraphQL API** (`timelogs`) — то есть из
  реального time tracking, который GitLab уже хранит по вашим issue и merge
  request'ам. Ничего вводить вручную не нужно.
- Vite dev-сервер поднимает небольшой middleware (`/api/proxy` в
  `vite.config.js`), который пересылает запросы на ваш GitLab с вашего
  компьютера — это нужно, чтобы браузер не упирался в CORS. Токен нигде не
  сохраняется на сервере и не уходит в сторонние сервисы — только в
  `localStorage` вашего браузера и напрямую в ваш GitLab.

## Запуск в браузере (для разработки)

```bash
npm install
npm run dev
```

Откройте адрес, который выведет Vite (обычно `http://localhost:5173`).

## Mac-приложение

Есть Electron-обёртка, чтобы не поднимать `npm run dev` каждый раз — двойной
клик по `.app`, и внутри само стартует локальный сервер (та же логика
проксирования, что и в `vite.config.js`, только встроенная в приложение,
порт выбирается автоматически).

Собрать `.app` и `.dmg`:

```bash
npm install
npm run dist:mac
```

Готовые файлы появятся в `release/`:
- `release/mac-arm64/GitLab Time Tracker.app` — можно сразу запускать
  (`open "release/mac-arm64/GitLab Time Tracker.app"`) или перетащить в `Applications`.
- `release/GitLab Time Tracker-*.dmg` — установочный образ.

Приложение не подписано Apple Developer ID (это требует платного аккаунта
разработчика), поэтому при первом запуске macOS Gatekeeper покажет
предупреждение «нельзя проверить разработчика». Это ожидаемо для локальной
сборки: правый клик по `.app` → **Открыть** → **Открыть** — подтверждение
нужно только один раз.

Быстрый запуск без сборки дистрибутива (для проверки):

```bash
npm run electron
```

## Подключение GitLab

1. В GitLab: **User Settings → Access Tokens**, создайте токен со scope
   `read_api` (этого достаточно, ничего дополнительно давать не нужно).
2. В приложении нажмите «Подключить GitLab», укажите адрес инстанса
   (`https://gitlab.com` или адрес self-managed сервера) и вставьте токен.

## Возможности

- Пресеты диапазона: сегодня / 7 дней / 30 дней / эта неделя / этот месяц /
  свой диапазон.
- График часов по дням с подсказкой при наведении.
- Разбивка времени по проектам.
- Список дней с деталями: issue/MR, проект, комментарий из `/spend`.
- Тёмная/светлая тема (авто по системной, плюс переключатель).
